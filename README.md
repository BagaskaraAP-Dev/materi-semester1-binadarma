## 🚀 Cara Menjalankan Program

### 1. Java (`belajar.java`)
Pastikan Java Development Kit (JDK) sudah terpasang.
```bash
# Kompilasi program
javac belajar.java

# Jalankan program
java belajar
```
**Output:**
```
Hello, World!
```

### 2. Python (`belajar.py`)
Pastikan Python 3 sudah terpasang.
```bash
# Jalankan program
python belajar.py
```
**Output:**
```
hello world
```
